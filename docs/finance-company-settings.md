# ตั้งค่าหัวเอกสาร Finance

เจ้าของร้าน (`owner`) เปิด Finance แล้วกด **ตั้งค่าหัวเอกสาร** ด้านบน
แก้ชื่อผู้ออกเอกสารภาษาไทย/อังกฤษ ชื่อแบรนด์ สาขา ที่อยู่ เลขประจำตัวผู้เสียภาษี
เบอร์โทร และอีเมล มีตัวอย่างก่อนบันทึก ช่องที่ไม่บังคับเว้นว่างเพื่อซ่อนบรรทัดได้
ชื่อภาษาไทยจำเป็น เลขผู้เสียภาษีถ้ากรอกต้องเป็นตัวเลข 13 หลัก (ตรวจรูปแบบ ไม่ตรวจทะเบียน)

การบันทึกใช้กับใบเสร็จและใบสำคัญจ่ายที่ออกใหม่ เอกสารเก่าคงข้อมูลบริษัทที่บันทึกไว้
ใน `companyProfileSnapshot` ของใบนั้น รายงานรายเดือนที่สร้างใหม่ใช้ข้อมูลบริษัทปัจจุบัน
การเปลี่ยนหัวเอกสารไม่เปลี่ยนยอดเงิน หมายเลขเอกสาร หรือโหมด Non-VAT
หากต้องแก้เอกสารที่ออกแล้ว ใช้ Void พร้อมเหตุผลแล้วออกใหม่ผ่านขั้นตอนเดิม

## การเก็บและสิทธิ์

- เก็บที่ `system_settings/finance_company` พร้อม revision, updatedAt และ updatedBy
- อ่านผ่าน `GET /api/finance-data?action=company:get`: owner หรือ ultra_admin
- บันทึกผ่าน `POST /api/finance-data` action `company:save`: owner เท่านั้น
- ส่ง `profile` เฉพาะช่องที่แก้ได้และ `revision` ที่อ่านล่าสุด การบันทึกค่ารุ่นเก่าตอบ 409
- เก็บ audit before/after ใน transaction เดียวกับการบันทึกค่า
- ออกเอกสารอ่านโปรไฟล์ใน transaction เดียวกับการออกเลขและสร้างเอกสาร
- ถ้ายังไม่เคยตั้งค่า ใช้ข้อมูล Ultra เดิม ไม่ต้อง migration หรือบันทึกค่าเริ่มต้นลง Live
- Firestore rules ที่ผู้ใช้ให้ไว้ปิดข้อมูล system_settings ยกเว้น pricing อยู่แล้ว
  จึงไม่ต้องเปิด Client read/write สำหรับค่าหัวเอกสารใหม่
- ยังไม่เพิ่มโลโก้ ลายเซ็น การตั้งค่า VAT หรือเลือกหลายบริษัทต่อเอกสาร

`tests/finance-company.test.mjs`: สิทธิ์ การตรวจข้อมูล ค่าเริ่มต้น การเว้นว่าง
การ escape ข้อความ ประวัติการแก้ การแก้พร้อมกัน และ snapshot ใบเดิม/ใหม่
`tests/firestore-rules.test.mjs`: ห้าม anonymous, customer และ owner claim
อ่าน/เขียนค่าหัวเอกสารโดยตรงผ่าน Client SDK
